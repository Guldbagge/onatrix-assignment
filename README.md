# Onatrix Assignment

## Overview
Onatrix Assignment is a web application built using a combination of C#, HTML, CSS, SCSS, and JavaScript. This project demonstrates various web development techniques and practices, providing a comprehensive example of a modern web application. The application is also a CMS (Content Management System) built with Umbraco.

## Features
- **C# Backend:** Utilizes C# for server-side logic and operations.
- **Responsive Design:** Styled with CSS and SCSS to ensure responsiveness across different devices.
- **HTML Integration:** Structured web content using HTML.
- **JavaScript Support:** Minimal JavaScript for enhanced interactivity.
- **Umbraco CMS:** Built with Umbraco for easy content management.

### Umbraco CMS
Onatrix Assignment is built with Umbraco, a powerful and flexible CMS platform. Umbraco allows for easy content management, enabling users to create, edit, and publish content seamlessly.
